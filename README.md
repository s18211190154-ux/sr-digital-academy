# SR Digital Academy

A responsive, single-file website concept for an academy with multiple course pathways.

## Included
- Paid professional courses, NSDA, ASSET, and SICIP project sections
- Eight sample course cards with category filters and live search
- Responsive layout and mobile navigation
- About section and inquiry form that opens a prefilled email draft
- No build step or external JavaScript dependencies

## Publish with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for GitHub Pages to finish deploying. The expected URL is:
   https://s18211190154-ux.github.io/sr-digital-academy/

## Before using this for real admissions
- Replace `hello@example.com` and the placeholder phone details in `index.html`.
- Verify current participation, approval, eligibility, fees, and intake dates for NSDA, ASSET, and SICIP. These labels and courses are sample content only.
- Replace sample course fees, durations, and descriptions with confirmed details.
- The contact form does not store submissions; it opens the visitor's email app. A backend or form service is needed to collect inquiries directly.
- This is a static front-end only. Student accounts, payments, course administration, and dashboards are not included.
